# 📊 Job Market Analysis

-> Overview
This project analyzes job market trends using Python and Power BI.
It collects job data, cleans the dataset, and builds an interactive dashboard to identify the most in-demand skills, cities, and technologies.

-> Features
- Job data collection
- Data cleaning and preprocessing
- Skill analysis
- City-wise job analysis
- Interactive Power BI dashboard

-> Technologies Used
- Python
- Pandas
- Power BI
- CSV
- Git & GitHub

->Project Workflow

-Fetch Job Data
-Clean Dataset
-Analyze Data

Create Power BI Dashboard
->Dashboard Insights
- Top Skills
- Top Hiring Cities
- Total Jobs
- Skill Distribution
